
# FitZone Fitness Center Web Application

FitZone is a responsive and interactive web application developed for a fictional gym in Kurunegala. The platform is designed to improve customer engagement and operational efficiency through digital services like training plans, nutrition guidance, and membership management.

## 💡 Key Features

- Role-based login for members, trainers, and admin users
- Training and meal plan browsing with dynamic pricing
- Membership sign-up, cancellation, and payment portal integration
- Profile management with options to edit or delete accounts
- Responsive design for mobile and desktop devices
- Admin panel for handling user queries and managing content
- Secure authentication, input validation, and access control

## 🛠️ Tech Stack

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** PHP
- **Database:** MySQL
- **Development Tools:** Visual Studio Code, WAMP/XAMPP Server
- **Mockups:** Moqups, Figma

## 🚀 How to Run

1. Install [WAMP Server](https://www.wampserver.com/en/) or XAMPP.
2. Clone/download this project and place it inside the `www/` or `htdocs/` folder.
3. Start Apache and MySQL from the server dashboard.
4. Import the `fitzone.sql` file in phpMyAdmin.
5. Access the app via `http://localhost/FitZone`.
